# AI 岗位描述样本

本目录用于 HireOS 面试项目的 JD 上传、AI 解析和候选人匹配测试。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `01-高级AI产品经理-企业智能平台.txt` | 与 AI 产品经理简历高度匹配 |
| `02-AI项目经理-行业智能化.txt` | 与 AI 项目经理简历高度匹配 |
| `03-高级后端工程师-AI平台.txt` | 与 AI 后端工程师简历高度匹配 |
| `04-高级产品设计师-AI体验.txt` | 与 AI 产品设计师简历高度匹配 |
| `05-财务运营经理-AI SaaS.txt` | 与财务运营经理简历高度匹配 |
| `06-全栈工程师-招聘平台.txt` | 用于测试不同技术方向的低匹配结果 |

## 建议测试方式

1. 先单独上传任意一份 JD，确认职位名称、职责和任职要求能够被 AI 正确提取。
2. 再分别关联 5 份简历，观察高匹配和低匹配岗位的差异。
3. 检查每一条 AI 解析结果是否有原文引用，并在人工核对后保存。
