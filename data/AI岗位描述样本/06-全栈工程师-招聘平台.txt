职位名称：全栈工程师
所属部门：招聘平台研发部
工作地点：上海
工作模式：全职
汇报对象：工程负责人

职位概述
我们正在寻找一位全栈工程师，负责招聘协作平台的业务功能开发，参与岗位管理、候选人流程、面试安排和用人决策等模块建设。该岗位更关注稳定的业务交付和前后端协作，不要求具备专门的 AI 平台研发经验。

主要职责
1. 使用 React、TypeScript 和组件库开发招聘平台的管理端页面。
2. 使用 Node.js、NestJS 或类似技术开发业务 API 和后台任务。
3. 负责岗位、候选人、面试安排、权限和通知等业务模块的开发与维护。
4. 参与数据库设计、接口设计、代码评审、自动化测试和线上问题排查。
5. 与产品、设计、测试和运营团队协作，按计划完成需求交付。

任职要求
1. 具备 3 年及以上全栈或前后端开发经验。
2. 熟练掌握 TypeScript、React、HTML 和 CSS。
3. 熟悉 Node.js、NestJS、Express 或其他服务端开发框架。
4. 熟悉 PostgreSQL、MySQL 或其他关系型数据库。
5. 了解 REST API、身份认证、权限控制和常见 Web 安全实践。
6. 具备良好的代码规范、测试意识和问题定位能力。

加分项
1. 有招聘、协作办公或 SaaS 管理后台开发经验。
2. 熟悉 Vite、Ant Design、Tailwind CSS 或 Playwright。
3. 有第三方会议、文件上传或邮件通知服务接入经验。

我们提供
参与招聘协作平台的核心业务开发，和产品及工程团队共同完善端到端招聘流程。
